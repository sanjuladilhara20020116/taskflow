# TaskFlow Task Management System

## Project Overview

TaskFlow is a full-stack task management application developed for the Koncepthive Full Stack Web Developer Intern technical assessment.

The system allows an authenticated administrator to create, view, update, delete, search, filter and sort daily tasks.

## Technology Stack

### Frontend

- React.js
- Vite
- React Router
- Axios
- React Hot Toast
- Custom responsive CSS

### Backend

- Node.js
- Express.js
- MySQL2
- JWT
- bcryptjs
- Express Validator
- Helmet
- CORS

### Database

- MySQL

## Main Features

- Administrator login
- JWT authentication
- Logout
- Dashboard task statistics
- Task creation
- Task viewing
- Task updating
- Task deletion
- Dynamic title search
- Status filtering
- Priority filtering
- Combined filters
- Newest sorting
- Oldest sorting
- Due date sorting
- Frontend validation
- Backend validation
- Pagination
- Dark mode
- Loading indicators
- Toast notifications
- Responsive desktop, tablet and mobile design
